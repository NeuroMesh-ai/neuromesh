## Discord servers where this would be relevant:

### OpenClaw Discord (we're already there)
Hey! Just released UnityBrain v4.1 — a P2P distributed AI network that connects machines running LLMs into a mesh. Multi-provider (Ollama, OpenAI, Anthropic, custom), CRDT memory sync, Ed25519 auth. No server, no accounts. MIT licensed.

It's designed to work as an OpenClaw skill too — you can query your P2P network from your agent. Happy to share more if anyone's interested.

https://github.com/unitybrain-ai/unitybrain

### Ollama Discord
Hey everyone! Built something that might be useful for those of you running Ollama on multiple machines. UnityBrain connects them into a P2P network — queries can fall back between nodes, memory syncs via CRDT, and you can also route to OpenAI/Anthropic as additional providers.

Lightweight (17MB RAM, Python), works with Tailscale or static config. MIT licensed.

https://github.com/unitybrain-ai/unitybrain

### r/selfhosted Discord
Self-hosted P2P AI network — no server needed, no Docker, no K8s. Just Python and a config file. Connect your machines, they discover each other via Tailscale, sync memory, and share AI queries. Multi-provider support (Ollama, OpenAI, Anthropic).

https://github.com/unitybrain-ai/unitybrain
