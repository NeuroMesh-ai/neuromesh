## ✨ Что такое NeuroMesh?

NeuroMesh объединяет машины в пиринговую ИИ-сеть. Ваши машины общаются напрямую, делят вычислительные мощности и модели — без зависимости от облака, без центрального сервера, без единой точки отказа.

**v5 добавляет публичную mesh-сеть:** присоединяйтесь к глобальной сети общих CPU, RAM, GPU и ИИ-моделей. Ваша приватная сеть остаётся приватной. Mesh — это дополнительный слой, который вы активируете по желанию.

**Короче:** Как BitTorrent, но для ИИ. Вы делитесь вычислениями, вы получаете доступ к 50+ моделям. Ваши данные остаются на вашей машине. E2E шифрование. Всегда.

### Предварительные требования
- Python 3.12+
- [Ollama](https://ollama.ai) запущенный локально (или облачная модель)

```bash
# Клонировать
git clone https://github.com/NeuroMesh-ai/neuromesh.git
cd NeuroMesh

# Запустить
python3 src/neuromesh_v5.py

# Или с файлом конфигурации
python3 src/neuromesh_v5.py --config config/bug.json
```

### Подключите свою сеть

```json
{
  "node_name": "мой-узел",
  "private": {
    "p2p_secret": "ваш-общий-секрет",
    "peers": [
      {"name": "другой-узел", "host": "192.168.1.100", "port": 8080}
    ]
  },
  "public_mesh": {
    "enabled": false
  }
}
```

Вот и всё. Ваша приватная сеть работает сразу. Хотите присоединиться к mesh? Установите `"enabled": true` и выберите, чем делиться.

## 🔑 Основные функции

### 🤖 Мульти-LLM провайдеры
- **Ollama** (локально) — обратная совместимость по умолчанию
- **OpenAI** — GPT-4o, GPT-4o-mini и т.д.
- **Anthropic** — модели Claude
- **Совместимые с OpenAI** — LM Studio, vLLM, любая пользовательская API
- Модели всех провайдеров доступны в P2P и mesh-сети

### 🔌 WebSocket связь в реальном времени
- Двунаправленный WebSocket на `/ws` эндпоинте
- Типизированные сообщения: `query`, `memory_sync`, `memory_update`, `ping/pong`, `auth`
- Автоматическое переподключение с экспоненциальной задержкой

### 🔐 Децентрализованная авторизация
- **Идентичность Ed25519** — каждый узел генерирует свою пару ключей
- **HMAC общий секрет** — более простая альтернатива для приватных сетей
- **Сеть доверия** — узлы ручаются друг за друга, транзитивное доверие
- **Ограничение скорости** на узел (алгоритм token bucket)
- **Скрытый режим** — невидимый узел, только доверенные пиры

### 🧠 Распределённая память (CRDT)
- **Бесконфликтные реплицированные типы данных** — никогда никаких конфликтов слияния
- **Gossip-протокол** — изменения распространяются автоматически
- **Векторные часы** — каузальный порядок событий
- **Поддержка TTL** — записи истекают автоматически

### 🤖 Маршрутизация ИИ-моделей
- **Локальные модели первыми** — запросы идут к локальному Ollama, когда возможно
- **Облачные модели по требованию** — синтаксис `model:cloud`
- **Фейловер на пиры** — маршрутизация к пиру, если локальная модель занята
- **Ансамблевый консенсус** — запрос к нескольким моделям, возврат лучшего ответа
- **Предохранители** — прекратить отправку запросов недоступным пирам

## 🌐 Публичная mesh-сеть

### Двойная сетевая архитектура

```
┌─────────────────────────────────────────────────────┐
│                    Узел (Вы)                        │
│                                                     │
│  ┌─────────────┐          ┌──────────────────┐     │
│  │ Приватная   │          │   Публичная mesh  │     │
│  │ сеть        │          │   трекер          │     │
│  │ p2p_secret  │          │ ┌──────────────┐ │     │
│  │ ┌─────────┐ │          │ │ Узел #42     │ │     │
│  │ │ Bug     │◄┼──P2P────┼─┤ 2ГБ RAM      │ │     │
│  │ └─────────┘ │          │ │ 30% CPU      │ │     │
│  │ ┌─────────┐ │          │ │ Ollama лок.   │ │     │
│  │ │ Pinky   │◄┼──P2P────┼─┤              │ │     │
│  │ └─────────┘ │          │ └──────────────┘ │     │
│  └─────────────┘          │ ┌──────────────┐ │     │
│                           │ │ Узел #789    │ │     │
│  ┌─────────────────┐      │ │ 8ГБ RAM      │ │     │
│  │ Resource Guard   │      │ │ RTX 4090     │ │     │
│  │ max_ram: 2ГБ    │      │ │ 4 модели     │ │     │
│  │ max_cpu: 30%    │      │ └──────────────┘ │     │
│  │ gpu_share: off  │      │                  │     │
│  │ priority: local  │      │  Трекер:        │     │
│  └─────────────────┘      │  announce/caps   │     │
│                           └──────────────────┘     │
└─────────────────────────────────────────────────────┘
```

Ваша **приватная сеть** (p2p_secret) полностью изолирована от **публичной mesh** (Ed25519 + Сеть доверия). Разные порты, разная авторизация, ноль утечек данных.

### Квоты на основе вклада

| Вклад | Баллы | Публичная квота |
|---|---|---|
| Ничего не поделено | 0 | 1 запрос / 5 мин |
| 1 модель поделена | +20 | 5 запросов / мин |
| 2+ модели поделены | +30 | 20 запросов / мин |
| 2ГБ RAM поделено | +20 | +10 запросов / мин |
| GPU поделено | +20 | +20 запросов / мин |
| 24ч аптайм | +10 | +5 запросов / мин |

**Больше делитесь = больше доступ.** Даже с нулевым вкладом вы получаете 1 запрос каждые 5 минут. Никто не заблокирован.

## 🛡️ Resource Guard

Ваша машина на первом месте. Resource Guard отслеживает CPU/RAM и автоматически приостанавливает публичный обмен, когда вы заняты.

```python
class ResourceGuard:
    def can_accept_request(self) -> bool:
        cpu_usage = psutil.cpu_percent(interval=0.1)
        ram_usage = psutil.virtual_memory().percent
        
        if self.priority == "local_first":
            if cpu_usage > 70 or ram_usage > 85:
                return False  # Пользователь занят
        
        if cpu_usage > self.max_cpu + 40:
            return False
        
        return True
```

**Локальный приоритет ВСЕГДА побеждает.** Если ваша машина занята, она отклоняет публичные запросы. Без исключений.

## 🧠 Адаптивный планировщик

Сеть выбирает лучшую стратегию в зависимости от количества доступных пиров. Никаких номеров версий, никаких ручных режимов.

| Доступных пиров | Стратегия | Возможности |
|---|---|---|
| 1–3 | Простая маршрутизация | Полные модели на одной машине |
| 4–10 | Частичное шардирование | Модели разбиты на 2–4 фрагмента |
| 11–50 | Полное шардирование + 2× репликация | Конвейерный параллелизм, избыточность |
| 50+ | Распределённый RAID RAM | Виртуальный RAM-диск, 3× репликация, асинхронный prefetch |

**Переходы происходят автоматически и без прерываний.** Пир присоединяется → планировщик перераспределяет. Пир отключается → реплики берут на себя. Вы ничего не замечаете.

## 💬 Постоянное хранилище разговоров

Ваши разговоры остаются на ВАШЕЙ машине. Точка.

- **Автосохранение** — Каждое сообщение сохраняется локально. Никакой кнопки «сохранить».
- **Возобновление** — Откройте NeuroMesh завтра, ваши разговоры на месте.
- **Поиск** — Найдите любой разговор по ключевому слову, дате, модели или тегу.
- **Экспорт** — Markdown, JSON, простой текст. Ваши данные, ваш формат.
- **Конфиденциальность** — Разговоры НИКОГДА не покидают вашу машину, если вы явно не синхронизируете их через приватный P2P.
- **Шифрование** — Опциональное локальное шифрование. Даже доступ к диску не позволит их прочитать.
- **Без трекинга** — Никакой аналитики, никакого обучения на ваших данных.

### Уровни конфиденциальности

| Уровень | Что происходит | Случай использования |
|---|---|---|
| **приватный** (по умолчанию) | Остается локально, никогда не синхронизируется | Личное, чувствительное |
| **синхронизированный** | Синхронизация только через приватный P2P | Между вашими устройствами |
| **общий** | Общий с определёнными пирами | Совместная работа |
| **публичный** | Опциональный вклад в mesh-базу знаний | Знания сообщества |

**По умолчанию: приватный. Всегда.**

## 🔒 E2E шифрование

Когда вы запрашиваете mesh, ваши данные зашифрованы сквозным шифрованием:

1. Ваш вопрос зашифрован сеансовым ключом
2. Каждый пир в конвейере расшифровывает только свой фрагмент, вычисляет, повторно шифрует
3. Только ВЫ можете расшифровать окончательный ответ

**Что может видеть каждый пир:**
| Данные | Видно? | Почему |
|---|---|---|
| Ваш оригинальный вопрос | ❌ Нет | Зашифрован вашим сеансовым ключом |
| Окончательный ответ | ❌ Нет | Зашифрован вашим сеансовым ключом |
| Входные/выходные тензоры своего фрагмента | ✅ Да | Необходимо для вычислений |
| Данные других фрагментов | ❌ Нет | Зашифрованы ключами других пиров |

**Это не обещание. Это криптография.** Даже если все пиры скомпрометированы, они не смогут прочитать ваши данные без вашего сеансового ключа — который существует только на вашей машине, только на время запроса.

## 📂 shared_models/ — Граница приватное/публичное

Выделенная папка, которая является **единственным интерфейсом** между вашими моделями и публичной mesh-сетью.

```
~/.neuromesh/
├── conversations/        → 🔒 Приватное (никогда не делится)
├── memory/               → 🔒 Приватное (никогда не делится)
├── config/               → 🔒 Приватное (никогда не делится)
├── shared_models/        → 🌐 Зона обмена (видна mesh)
│   ├── glm-5.1/          → Символическая ссылка на ~/.ollama/models/glm-5.1
│   ├── llama3/           → Копия или символическая ссылка
│   └── mistral/          → Копия или символическая ссылка
└── ollama/               → 🔒 Приватное хранилище Ollama
```

```bash
neuromesh share glm-5.1    # Поделиться моделью (создаёт символическую ссылку)
neuromesh unshare glm-5.1  # Прекратить делиться (удаляет только ссылку)
neuromesh shared            # Список общих моделей
```

**Mesh НИКОГДА не читает за пределами `shared_models/`.** Прекращение обмена мгновенно — mesh теряет доступ в момент удаления ссылки.

## 🖥️ Десктопный интерфейс

4 вкладки, никакого терминала:

- **💬 Чат** — Запросы к ИИ-моделям, история разговоров, поиск, экспорт
- **📊 Обмен** — Ползунки CPU/RAM/GPU, переключатели обмена моделями, статистика вклада
- **🔒 Сеть** — Приватные пиры, узлы mesh, проверка изоляции
- **⚙️ Конфигурация** — Имя узла, настройки mesh, хранилище, пороги приостановки

Работает в любом браузере на `localhost:8080`. Устанавливается как PWA для десктопа/мобильных устройств.

## 🔧 4 режима развёртывания

| Режим | Случай использования | Интерфейс |
|---|---|---|
| 🔧 **Сервис** | Серверы, VPS, headless | Только API (systemd/Docker) |
| 🖥️ **Приложение** | Полный десктопный опыт | GUI с 4 вкладками |
| 📍 **Sidekick** | Повседневное использование, минимум | Иконка в системном трее + мини-чат |
| 🔌 **Плагин** | Интегрирован в ваш рабочий процесс | VS Code, браузер, Obsidian, терминал |

```bash
neuromesh serve          # Сервис (headless)
neuromesh app            # Приложение (GUI)
neuromesh sidekick       # Sidekick (системный трей)
neuromesh plugin --vscode  # Плагин (VS Code)
```

Все 4 режима используют одно ядро. Один бинарник, четыре образа жизни.

## 🔒 Безопасность и конфиденциальность

- **Приватная сеть:** зашифрована с p2p_secret (без изменений с v4)
- **Публичная mesh:** идентичность Ed25519 + TLS для транспорта
- **E2E шифрование:** запросы зашифрованы сквозным шифрованием при распределённом выводе
- **Никаких утечек данных** между приватной и публичной сетями
- **Публичные запросы в песочнице:** нет доступа к приватной памяти
- **Resource Guard:** автоматическая приостановка обмена, когда ваш ПК занят
- **Скрытый режим:** делитесь вычислениями, но оставайтесь невидимым на трекере
- **Без логирования:** публичные пиры mesh никогда не хранят запросы или ответы

### Авторизация

Все эндпоинты записи требуют HMAC-авторизацию:

```bash
TIMESTAMP=$(date +%s)
SIGNATURE=$(echo -n "/api/query:${TIMESTAMP}" | openssl dgst -sha256 -hmac "ваш-секрет" | awk '{print $NF}')

curl -X POST http://localhost:8080/api/query \
  -H "X-NeuroMesh-Auth: ${SIGNATURE}" \
  -H "X-NeuroMesh-TS: ${TIMESTAMP}" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Привет","model":"glm-5.1:cloud"}'
```

## 🔄 Путь миграции (v4 → v5)

1. v5 **обратно совместима** с v4
2. Конфигурация приватной сети работает точно так же, как раньше
3. Раздел `public_mesh` **опционален** — отключён по умолчанию
4. Существующие узлы v4 могут общаться с узлами v5 в приватной сети
5. Публичная mesh — **opt-in:** установите `public_mesh.enabled = true`
