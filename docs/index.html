Features

Everything you need for distributed, trustless AI compute.

🧠

Multi-LLM

Route queries across Ollama, OpenAI, Anthropic, Google, Mistral, and more — simultaneously.

🔗

CRDT Memory

Conflict-free replicated shared memory across all nodes. Eventually consistent, always available.

🔑

Ed25519 Auth

Cryptographic identity for every node. Signed messages, verified trust, zero central authority.

🕸️

P2P Mesh

Full libp2p mesh networking. No central server, no single point of failure, no gatekeepers.

🛡️

Resource Guard

Per-node resource limits. CPU, memory, and GPU budgets enforced locally — no exploitation.

💰

Credit System

Contribute compute, earn credits. Spend credits, get answers. Fair, transparent, peer-to-peer.

🎯

Specialist Router

12 specialty schemas auto-route queries to the best-qualified nodes in the network.

🔄

Network Sync

State synchronization across the mesh. New nodes catch up instantly via CRDT gossip.

Architecture

A flat P2P mesh — no masters, no minions.

Quick Start

Up and running in under 2 minutes.

bash# Install NeuroMesh $ npm install -g neuromesh # Initialize your node identity $ neuromesh init ✓ Generated Ed25519 keypair ✓ Node ID: 12D3KooW...q7Rx # Join the mesh $ neuromesh start ✓ Connected to 23 peers via libp2p ✓ CRDT memory synced (142 entries) ✓ Credit balance: 1000
bash# Query the mesh $ neuromesh -q "Explain CRDTs in simple terms" → Routed to specialist: distributed-systems → Response from node 12D3KooW...pLm9 CRDTs (Conflict-free Replicated Data Types) are data structures that can be replicated across multiple computers and merged without coordination, always converging to the same state...

6 Multi-LLM Modes

🔀 Round Robin

Distribute queries evenly across all available LLMs. Simple load balancing.

⚡ Fastest

Route to whichever LLM responds first. Speed-optimized.

🏆 Best Quality

Always use the highest-rated model for the specialty. Quality-first.

🗳️ Vote

Query multiple LLMs, aggregate responses by consensus. Democratic answers.

📊 Benchmark

Run same query across all LLMs, compare outputs side-by-side.

🎯 Adaptive
